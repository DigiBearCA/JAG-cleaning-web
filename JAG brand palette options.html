Shape, spacing and type rules

These rules stay the same whichever palette the client chooses, so the brand looks consistent on the website, quotes, and print. Values are in pixels for the website.

Border radius

JAG uses a pill language: every button and every single-line input is fully rounded. That gives a soft, friendly, approachable feel. To keep the system consistent, cards and panels use large radii, so the pill shapes look like part of the same family. We avoid small 4 to 8px corners on interactive elements.

Pill (999px)Buttons, text inputs, selects, search, tags, chips, toggles
16px, smallDropdown menus, tooltips, small popovers
24px, cardsService cards, quote form box, alerts, textarea
32px, largeHero image frames, big panels, modals

Where not to use a pill: anything that holds more than one line of text. Textareas, alerts, and cards use 24px instead, because a long pill with wrapped text looks awkward and breaks.

Where not to use border radius (0px):

LogoNever round or crop the mark
Full-width sectionsHero, footer, and banner edges
Edge-to-edge imagesPhotos that bleed to the screen edge
Dividers and tablesLines, table cells, accent bars
Vehicle and printVan wraps and signs use square, clean edges

Nested shapes: the inner radius equals the outer radius minus the padding between them. A photo inside a 24px card with 16px padding gets an 8px radius. Pills inside a card stay fully round.

Spacing

Everything sits on a 4px grid. Pill shapes need extra side padding, because the curved ends cut into the space, so text never sits against the curve. Use bigger gaps between sections than inside components, which keeps the layout calm and clean.

4, tightIcon to label
8, smallBetween related items
16, baseGap between stacked form fields
24, mediumBetween cards, form fields
28, pill buttonLeft and right padding inside buttons
32, largeCard padding on desktop (24 on mobile)
48, section (mobile)Space above and below sections
64, sectionSpace above and below sections
96, heroTop and bottom of the hero

Page container: 1120px wide at most, with 24px side margins on desktop and 16px on mobile.

Pill button48px tall, 28px side padding, 8px between icon and label, 12px between side-by-side buttons. Small version: 40px tall with 20px padding. Minimum width 120px.
Pill input48px tall, 24px side padding so text sits clear of the curve, 1.5px border. Label 8px above, 16px between fields. Error text sits 24px from the left to line up with the input text.
Textarea24px radius, not a pill. Padding 16px top and bottom and 24px sides, minimum height 120px.
Cards24px radius with 32px padding on desktop and 24px on mobile. 24px gap between cards.

Other rules

Borders1px hairline for cards, 1.5px for outlined buttons and inputs. Use the primary color or a light tint.
Focus state2px ring in the primary color, 2px away from the edge, following the pill shape. Never remove it.
ShadowsFlat by default. At most one very soft shadow on floating items like menus and modals.
IconsOutline style, 24px, 1.5px stroke, rounded line ends. Never mix filled and outline icons.
Text alignmentLeft-align body text. Center only short headlines and button labels.
Color useAccent only on call-to-action buttons and small highlights. Never use it for body text.
ImagesUse 24 to 32px corners on framed photos, 0px on full-width banners. Bright, natural light and real teams.

Colors apply roughly 60% base, 30% primary, and 10% accent. Check text contrast on the accent buttons before final build.
